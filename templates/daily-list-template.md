# 每日清单模板

规则:一天 5–6 个,不刷量。**给多了人反而投不出去。**

```markdown
# 今日清单 · YYYY-MM-DD(<城市…>)

| # | 公司 · 岗位 | 地点 · 薪资 · 年限/学历 | 为什么配 | 缺口 |
|---|---|---|---|---|
| 1 | | | | |

备选:<公司 岗位 薪资 年限(一句话为什么备着)>

## 还没扫

<城市 / 关键词 / 平台>

## 完整评分

<哪些有 jobs/<公司>-<岗位>.md,哪些只是标签级粗评>
```

写法要求:
- 「为什么配」一句话,指向**具体证据**,不写「经验匹配」。
- 「缺口」一句话,能补的写补法,不能补的写「认了,面试这样答」。
- 粗评和细评**必须分开标**。
- 排序按匹配度,不按薪资。

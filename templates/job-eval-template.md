# 单条岗位评分模板

```markdown
# <公司> · <岗位>(<城市>)

评估日 YYYY-MM-DD。来源:<平台> · <链接> · <jobId>
证据编号见 <证据库路径>。

## 一句话结论

**X/5,<可投 / 可试 / 不投>。<一句人话理由>**

## 基本信息

地点 / 薪资(注明是否 ·13薪) / 工作方式 / 职级 / 公司规模与阶段 / 行业

## 逐项拆

| 要求 | 现有匹配 | 缺口 / 补齐动作 |
|---|---|---|
| | | |

## 直接证据 / 相邻可迁移

- 直接:<编号 + 一句话>
- 可迁移:<编号 + 一句话,注明「迁移」>

## 本次主讲 / 应弱化

- 主讲:
- 弱化:
- 别碰:

## 要跟本人确认

1. 地点?
2. 薪资/职级口径?
3. 行业偏好?

## 下一步

细评 / 补材料 / 直接投 / 放弃 + 谁来做
```

## 评分口径速记

5 = 硬要求全中且核心项目直接对口;4 = 全中或只差一项软的;3 = 能面但缺口不小;2 = 有硬要求过不去;1 = 方向都不对。

# 采岗:平台接口、城市码、节奏

记录时间 2026-10-27。**这些都是当时的观察,平台随时会改**;变了就重新探一次,不要照抄。

## BOSS 直聘(可结构化采集)

前提:agent 能在**已打开的 zhipin.com 页面上下文里**发 fetch(浏览器控制 / devtools / evaluate 均可),用同一份 cookie。

### 搜索接口

```
GET /wapi/zpgeek/search/joblist.json
  ?scene=1
  &query=<关键词,URL 编码>
  &city=<城市码>
  &page=1
  &pageSize=30
```

返回 `zpData.jobList[]`,每条常用字段:

| 字段 | 含义 |
|---|---|
| `jobName` / `brandName` | 岗位 / 公司 |
| `salaryDesc` | 薪资。**未登录时为空字符串** |
| `cityName` / `areaDistrict` / `businessDistrict` | 地点 |
| `jobExperience` / `jobDegree` | 年限 / 学历 |
| `skills[]` | 技能标签,做初筛最省钱 |
| `encryptJobId` / `securityId` | 详情接口要用 |
| `brandStageName` / `brandScaleName` / `brandIndustry` | 公司阶段/规模/行业 |

### 详情接口

```
GET /wapi/zpgeek/job/detail.json?securityId=<sid>&lid=<encryptJobId>
```

返回 `zpData.jobInfo`,含 JD 正文。不登录时正文会被截断成「登录查看完整内容」。

### 节奏(用血换的)

- 一次 evaluate 里连打 9 个请求(3 城 × 3 词)**能过**。
- 紧接着再打 9 个,多半返回 `{"code":35,"message":"您的IP地址存在异常行为."}`。
- **一个平台一批 = 3 城 × 3 词,然后歇 15 分钟以上**;当天要更多就换平台。
- 登录后额度更宽,但**账号也有风险**,别因为登录了就可劲打。
- 触发异常后不要重试、不要换 IP、不要绕验证码——等,或者换平台。

### 关键词

从「方向分层」取,例如:视觉算法、目标检测、图像算法、机器视觉、图像处理、SLAM、强化学习、多模态、算法工程师。
泛词(「算法工程师」「AI」)会淹掉信号,只在岗位少的城市用。

## 备用平台

- **智联招聘 / 51job / 猎聘**:搜索页可读,但结构化程度差,多半要逐页读 DOM;有的板块要登录。**当 BOSS 限流时的兜底**,别当主力。
- **企业官网/校招页**:定向投递时最靠谱(尤其国资、科研院所),但要一个个人肉找。
- 只用**人工节奏 + 正常账号**;不做代理池、不做 UA 伪装、不绕验证码。这一条不可协商。

## 采集脚本

`scripts/boss-search.js`:一段可直接在页面上下文里跑的采集函数(城市列表 + 关键词列表 → 去重压缩后的数组)。改城市码和关键词就能用。
